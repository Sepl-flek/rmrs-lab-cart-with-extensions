# РиМРС. Программа с расширениями

Корзина интернет-магазина: основная программа написана на Python, а правила
скидки находятся в отдельном Lua-скрипте `extensions/discount.lua`.

## Запуск

Нужен Python 3.12. Из папки проекта выполните в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Компиляция не нужна. Lua встроен в библиотеку Lupa, которая устанавливается
из `requirements.txt`.

### Через Docker

Запустите Docker Desktop. Из папки проекта выполните в PowerShell:

```powershell
docker build -t rmrs-cart .
docker run --rm -it --mount "type=bind,source=$((Get-Location).Path)/extensions,target=/app/extensions,readonly" rmrs-cart
```

Подключение папки позволяет контейнеру видеть изменения локального Lua-файла.

## Как увидеть изменение поведения

1. Запустите программу. Сумма корзины — 4000 рублей, скидка 10%, к оплате — 3600 рублей.
2. В `extensions/discount.lua` замените `local DISCOUNT_PERCENT = 10` на
   `local DISCOUNT_PERCENT = 20` и сохраните файл.
3. В той же консоли появится новый итог — 3200 рублей. Перезапускать программу,
   компилировать её или пересобирать Docker-образ не нужно.

Для выхода нажмите Ctrl+C.

## Как работает расширение

`main.py` каждые 0,5 секунды читает Lua-файл и проверяет, изменился ли его текст.
При изменении создаётся встроенный интерпретатор `LuaRuntime` из Lupa.
Вызов `lua.execute(source)` исполняет скрипт, а `lua.globals().calculate`
получает объявленную в нём функцию `calculate(cart)`.

Программа преобразует корзину в таблицу Lua через `lua.table_from` и вызывает
функцию расширения. Скрипт возвращает таблицу с размером скидки `discount`
в копейках и пояснением `message`. Python проверяет ответ, вычитает скидку
из суммы корзины и выводит результат.

При ошибке чтения, выполнения скрипта или неверном ответе программа сообщает
об ошибке и сохраняет последний успешный результат. После исправления файла
работа продолжается. Скрипт должен быть доверенным: защиты от бесконечного
цикла в нём нет.
